## Ringkasan Singkat

Praktikum ini bertujuan melihat apakah model MLP mengalami overfitting saat dilatih menggunakan sebagian data Fashion-MNIST, kemudian menilai beberapa cara untuk menguranginya. Pada model baseline, validation loss mencapai nilai terendah 0,4568 di epoch 10, lalu meningkat hingga 0,7231 pada epoch 30 meskipun train loss terus menurun. Dari tiga strategi yang dibandingkan, dropout 0,5 memberikan hasil validasi terbaik dengan val_loss 0,4304 dan gap 0,1939. Random search memilih konfigurasi hidden 128, dropout 0,2, weight decay 0, dan learning rate 1e-3, dengan val_loss 0,4293. Setelah dilatih ulang, model akhir memperoleh test loss 0,4651 dan akurasi 0,8378. Perbedaan validation loss dan test loss sebesar 0,0358 menunjukkan performa keduanya relatif berdekatan, tetapi hasil satu kali evaluasi ini tidak dapat dijadikan bukti keunggulan model secara umum.

## 1. Tujuan dan Hipotesis

### 1.1 Tujuan

1. Membuktikan baseline overfit dari kurva (val_loss naik setelah epoch terbaik sementara train loss turun).
2. Membandingkan penurunan gap dan val_loss tiga strategi yang masing-masing mengubah satu faktor dari baseline.
3. Memilih konfigurasi final dari 12 trial random search memakai validation loss, melatih ulang, dan melaporkan angka test satu kali.

### 1.2 Hipotesis sebelum eksperimen

| Perbandingan | Prediksi | Alasan teknis |
|---|---|---|
| Dropout 0,2/0,5 vs baseline | Keduanya menurunkan gap (0,5 lebih kuat); val_loss terbaik ikut turun sedikit | Dropout membatasi ko-adaptasi unit sehingga menekan variansi dengan harga train loss naik |
| Trial kapasitas besar vs kecil | Kapasitas besar belum tentu menang | Tanpa learning rate yang cocok, model besar pada 3.000 citra mudah overfit atau lambat konvergen |

## 5. Analisis dan Pembahasan

| Unsur | Isi |
|---|---|
| Klaim | Dropout_0.5 memenangkan kedua metrik; learning rate memutuskan peringkat trial |
| Bukti | Gambar 1 (gap −0,0870, val −0,0264) dan Gambar 2 (lima terbawah lr 1e-4) |
| Penalaran | Dropout menekan ko-adaptasi yang menjadi sumber variansi pada data kecil; lr 1e-4 terlalu kecil untuk konvergen dalam 30 epoch sehingga trialnya tersensor early stopping |

1. **Perbandingan dengan hipotesis:** hasil mendukung dugaan bahwa dropout dapat menekan gap, dan dropout 0,5 memberi penurunan terbesar. Model dengan kapasitas besar juga tidak otomatis menjadi model terbaik; konfigurasi terpilih menggunakan hidden 128.
2. **Run terbaik dan run terburuk:** terbaik random_06/final (val 0,4293); terburuk random_11 (lr 1e-4, hidden 64, val 0,5703, gap hanya 0,0468 karena underfit).
3. **Trade-off:** dropout_0.5 menaikkan train loss (0,2364 vs 0,1759) tetapi menurunkan val loss; model final 5,7× lebih kecil dari baseline (118.282 vs 669.706) dengan val lebih baik.
4. **Anomali atau hasil gagal:** tidak ada run gagal (semua status ok/early_stopped). Train loss epoch ke-30 dropout_0.2 (0,0450) sedikit di bawah baseline (0,0532), di luar dugaan karena dropout 0,2 terlalu lemah menahan hafalan.
5. **Generalisasi:** gap final 0,1864 lebih kecil daripada gap terakhir baseline sebesar 0,6699. Selisih val-test 0,0358 menunjukkan kedua nilai loss relatif berdekatan, tetapi tidak cukup untuk menyimpulkan bahwa model pasti unggul pada data lain.

### Jawaban pertanyaan analisis modul

1. **Awal overfit baseline:** epoch 11; bukti val_loss minimum 0,4568 pada epoch 10 lalu naik ke 0,7231 sementara train loss turun ke 0,0532.
2. **Penurun gap dan val_loss terbesar:** keduanya dropout_0.5 (−0,0870 dan −0,0264).
3. **Parameter terbanyak di puncak:** tidak; puncak 118.282 parameter, maksimum 269.322 di peringkat 2/6/8.
4. **Paling berpengaruh dan keterbatasannya:** learning_rate; terbatas pada 12/81 kombinasi satu seed sehingga terikat konfigurasi tersampel dan sensor early stopping.
5. **Selisih val-test:** 0,0358 (0,4293 vs 0,4651); yang boleh disimpulkan hanya tidak ada bukti kebocoran, bukan superioritas umum.

## 6. Kesimpulan dan Keterbatasan

### 6.1 Kesimpulan

Model baseline menunjukkan overfitting karena validation loss meningkat setelah epoch 10 sementara train loss terus menurun. Strategi dropout 0,5 menghasilkan perbaikan terbaik di antara strategi regularisasi yang diuji. Dari 12 percobaan random search, konfigurasi hidden 128 dipilih karena menghasilkan validation loss terendah, yaitu 0,4293, dengan jumlah parameter yang lebih sedikit dibandingkan baseline. Evaluasi test satu kali menghasilkan loss 0,4651 dan akurasi 0,8378. Temuan ini berlaku pada pengaturan eksperimen ini dan masih perlu diuji menggunakan seed serta konfigurasi lain.

### 6.2 Keterbatasan

- Subset 3.000 citra dan 12/81 trial satu seed: selisih kecil (0,4293 vs 0,4342) tidak signifikan dan interaksi hyperparameter tidak terpetakan.
- Waktu CPU berfluktuasi antar run sehingga perbandingan runtime indikatif.
- Kelas atasan (Shirt, Pullover, Coat) mendominasi confusion test sehingga accuracy agregat menyembunyikan kelemahan per kelas.

### 6.3 Tindak lanjut

Satu eksperimen paling bernilai: ulangi 12 trial pada 3 seed data berbeda dengan anggaran epoch adaptif (tanpa sensor dini untuk lr kecil), untuk menguji stabilitas peringkat dan signifikansi selisih trial teratas.
